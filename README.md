
# Traffic CART
### CART Modelling for Concurrent Traffic Density Estimation and Priority Classification

🚀 **Live Demo:** [Open Traffic CART](https://traffic-cart-cart-modelling-for.onrender.com/)

A Flask-based machine learning dashboard that estimates traffic density conditions and classifies traffic priority using road and network parameters.

## Features
- Traffic condition prediction: Low, Medium, High
- Traffic priority classification
- Dataset and exploratory data analysis pages
- Flask web application with machine learning models
